# 模板保存按钮布局调整

## 目标

将模板参数编辑区的“保存”按钮从请求地址栏移至左侧参数面板右下角，使地址栏只承担请求方法与 URL 编辑职责。

## 交互与样式

- 保存按钮始终位于左侧参数面板右下角。
- 参数内容滚动时，按钮仍保持可见。
- 默认样式为纯黑背景、白色文字，不使用渐变。
- 保留现有的“保存中”“已保存”“保存失败”状态和保存事件逻辑。
- 不修改右侧代码预览、参数表格和后端接口。

## 实现范围

- 调整 `TemplateFilePreview.vue` 中保存按钮的 DOM 位置。
- 调整 `style.css` 中地址栏列结构及保存按钮定位样式。

## 验收标准

- 地址栏不再显示保存按钮。
- 保存按钮显示在参数面板右下角，黑底白字。
- 点击按钮仍调用原有保存逻辑，禁用态和状态文字正常。
