# MCP 代码工作台前端设计

## 核心架构

页面不存在“快速生成模式”和“项目模式”。项目文件树始终存在，每个 Tool 自带“生成代码”和“添加到项目”操作。

整体使用类似代码编辑器的三栏结构：

- 左侧资源管理器：项目文件树、新建文件和新建文件夹。
- 中间编辑区：展示当前 Tool 定义或当前文件节点。
- 右侧 Tool 仓库：按 HTTP、SSE、WS 分类选择 Tool。

## 交互规则

点击右侧 Tool 后，中间显示其名称、描述、请求方法、路径、参数和返回 Schema。Tool 详情自带两个操作：直接生成代码，或添加到左侧当前选中的文件夹。

点击左侧文件树节点后，中间切换为文件或文件夹视图。选中的目标文件夹会保留；用户再次选择 Tool 后，可以将其加入该文件夹。

当前项目树写入仍是前端本地状态，直到后端提供添加 Tool 和文件节点的持久化接口。

## 视觉原则

采用代码编辑器式框架和 Bento 信息组织，减少嵌套白色卡片。中间编辑区承担视觉重心，两侧栏更轻、更紧凑。颜色以灰绿中性色、深色代码区域和 HTTP 方法色为主，不使用蓝紫渐变，不在界面中直接使用“卡带”“播放器”等比喻文案。

## 组件

- `App.vue`：维护 Tool、文件树、当前编辑对象和本地树操作。
- `ProjectExplorer.vue`：左侧文件资源管理器。
- `EditorWorkspace.vue`：中间 Tool 详情、文件预览及 Tool 操作。
- `ToolSidebar.vue`：右侧 Tool 仓库。
- `FileTree.vue`、`FileTreeNode.vue`：递归文件树。

## 验证

- Vue 生产构建成功。
- 页面不存在模式切换。
- 文件树和 Tool 仓库始终可见。
- Tool 自带生成代码和添加到项目操作。
- 点击文件和 Tool 可以切换中间编辑内容。
